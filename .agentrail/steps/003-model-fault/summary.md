mlos-objman: object table + arena + fault path. ModelFault carries class/model/layer/tensor/tile/session/cost -- what a page fault cannot say, and what every PRD policy needs. Five host tests pin the properties that matter: a fault names the layer (not an address) and its cost includes transfer not just latency; a HIT does not reach the provider (the fast-path constraint); four sessions acquiring one layer cause ONE fetch with share_count 4 (the basis of parameter-major scheduling, tested now so it cannot quietly stop being true); a full arena returns NoBudget with the fault record intact and the resident object undisturbed; and BadObject vs NoProvider are distinguished. Arena is a bump allocator on purpose -- eviction is M3, and a general allocator would let the manager succeed at exactly the point where 'what should have been evicted' is the question being dodged. ObjectMeta now carries home (provider+handle) and residency (tier+resident_at) separately, since collapsing them would mean an object could only be fetched once. The arena is safe code because it never dereferences: the safety boundary is the provider, the one place that touches memory.
