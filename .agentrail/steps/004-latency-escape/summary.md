The latency escape. Waiting::at carries waited (other sessions' acquires since this session's token became due, less its own) and ceiling (Contract::latency_ceiling, renamed from _ns; the unit is acquires, the kernel's clock). ParameterMajor serves the lowest overdue session before the lockstep rule; once overdue it runs its token alone, so a period is bounded by the token plus twice the ceiling (tested). Lane {session, ceiling, tokens} replaces the tuple; session new [KIB] [WAIT] in the shell. Measured (status.md table): lockstep costs session 1 ~11% in period for 16x fewer reads; ceiling 512 -> period 817 for +15% reads; 256 -> 561 for +5%; 128 -> 433 for 8x reads (the session runs a token ahead and the group loses the sharing). Break-even near a quarter of a token. Lesson: the first wait definition (gap between a session's own accesses) never fired under lockstep; the table showed it. sw-checklist 14, unchanged.
